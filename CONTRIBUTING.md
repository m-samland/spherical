# Contributing to spherical

Contributions are welcome.
The [contributing guide](https://spherical-hci.readthedocs.io/en/latest/contributing/index.html) describes which contributions fit the package, the checklist every pull request must meet, and how to set up a development environment, run the tests and build the documentation.

Open an [issue](https://github.com/m-samland/spherical/issues) before you start anything larger than a small bug fix or a documentation correction, and open pull requests against `develop`.
